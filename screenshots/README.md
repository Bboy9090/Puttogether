## How to Add Screenshots

1. Open https://puttogether.netlify.app in your browser
2. Use browser developer tools or screenshot tools to capture images
3. For mobile screenshots, use actual mobile devices or browser mobile emulation
4. Save screenshots as PNG files with descriptive names
5. Place them in this directory
6. Update the main README.md with image references

## Recommended Tools

- **macOS**: Command + Shift + 4 (built-in screenshot)
- **Windows**: Snipping Tool or Windows + Shift + S
- **Linux**: GNOME Screenshot or Flameshot
- **Mobile**: Device screenshot (varies by platform)
- **Browser**: Browser DevTools device emulation for mobile views

## Image Guidelines

- **Format**: PNG (supports transparency and is good for UI screenshots)
- **Resolution**: High DPI (2x) for clarity, but optimized for web
- **Dimensions**: Max width 800-1200px for desktop, 375-414px for mobile
- **File size**: Compress images to keep them under 500KB each
- **Privacy**: Ensure no real card numbers are visible in screenshots
